# Segurança

## Como relatar uma vulnerabilidade

Não publique detalhes de uma vulnerabilidade de segurança em uma issue pública.

Antes da publicação oficial, defina um endereço de contato específico para segurança e substitua este trecho por uma forma privada de contato.

Inclua, quando possível:

- versão do EditePDF;
- versão do Windows;
- passos mínimos para reproduzir;
- impacto observado;
- arquivos de exemplo sem informações pessoais ou confidenciais.

## Escopo

Relatos de falhas de segurança do aplicativo, empacotamento, processamento de PDF e dependências são bem-vindos.

Problemas de uso comum ou falhas funcionais devem ser registrados pela área de Issues.
